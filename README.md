# ميديا v2 — نظام المحتوى العربي الآلي

إعادة بناء كاملة لخط معالجة الأخبار مع تحسينات الجودة والموثوقية.

## البنية

```
app/
  arabic.py        تطبيع عربي (نسخة مطابقة منفصلة عن نسخة العرض) + تنظيف Unicode/RTL
  dedup.py         إزالة تكرار 3 مراحل: Hash -> MinHash LSH + Levenshtein -> Embeddings
  clustering.py    تجميع الأحداث (HDBSCAN أو تجميع احتياطي بدون اعتماديات)
  llm.py           عميل موحد OpenAI/Anthropic/Gemini + تتبع التكلفة + وضع mock
  judge.py         مقيّم متقاطع (نموذج مختلف عن المولّد) + تحقق آلي من الادعاءات
  guardrails.py    حواجز رخيصة أولًا (طول، أنماط محظورة، بيانات خاصة، نسبة العربية)
  pipeline.py      المنسّق الرئيسي مع تسجيل التكلفة والزمن ونسخة البرومبت
  db.py            تخزين sqlite3 قياسي: مصادر، مقالات (مع سجل المكررات)، مجموعات، توليدات
  buffer_client.py نشر Buffer مع DRY_RUN افتراضيًا
streamlit_app.py   لوحة مراجعة RTL + مؤشرات جودة
```

## التشغيل

```bash
pip install -r requirements.txt
cp .env.example .env   # املأ المفاتيح
python demo.py         # تجربة بدون مفاتيح (وضع mock)
streamlit run streamlit_app.py
```

## سياسة النشر

- `AUTO_PUBLISH=false`: كل شيء يمر على المراجعة البشرية.
- `AUTO_PUBLISH=true`: يُعتمد تلقائيًا فقط إذا: متوسط التقييم ≥ 4/5،
  verdict=pass من نموذج مختلف، لا ادعاءات غير مطابقة، واجتاز الحواجز.

## العتبات المرجعية

| المرحلة | العتبة |
|---|---|
| Cosine (embeddings) | 0.95 |
| Levenshtein عنوان / محتوى | 0.97 / 0.92 |
| تجميع الأحداث | 0.55 |
| الاعتماد الآلي | متوسط ≥ 4.0 |

## ملاحظات

- التطبيع العربي يُطبق على نسخة المطابقة فقط؛ النص الأصلي يُحفظ كما هو للنشر.
- المقالات المكررة تُحفظ مع ربطها بالمقال الأب لأغراض التدقيق.
- كل خطأ يرفضه المراجع يجب تحويله لحالة اختبار دائمة.
- فعّل الحزم الاختيارية في requirements.txt للجودة الكاملة.
